# ParrillaEnCasa.com

Guía especializada en español para elegir **parrillas eléctricas de interior para casas y departamentos** en Amazon Estados Unidos, comparando modelos de **George Foreman, Cuisinart, Hamilton Beach y Ninja** según precio, espacio ocupado, porciones simultáneas y facilidad de limpieza, junto a **pinzas, termómetros y placas de repuesto compatibles**.

- **Stack:** Next.js 16 App Router (100 % SSG estático), Tailwind CSS v4, GSAP ScrollTrigger, Lenis
- **Contenido:** 1,332 guías editoriales (1,000 SEO + 320 Transaccionales Amazon + 12 Hubs Pilares) + 7 páginas legales e institucionales (`1,340` URLs estáticas)
- **Afiliados Amazon:** `parrillaencasa-20` (Amazon.com EE. UU. principal) y `parrillaencasa-21` (Amazon.es conmutador Europa)
- **Asesor IA y Generación de Imágenes:** Supabase (`ehwjvuhbimqakvzqbvvg`) — Edge Functions `parrillaencasa-chat` (`gpt-4o-mini` predeterminado) y `parrillaencasa-images` (`gpt-image-1`, `quality: "medium"`, WebP `< 100 KB`)
